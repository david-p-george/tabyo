This site is an instance of **tabyo** — an aligned reader for an editable
biblical edition.

- Left: the Greek text (SBLGNT base, plus the editor's adopted readings).
- Right: an English translation (Berean Standard Bible base, plus the
  editor's revision), aligned verse row by verse row.
- Underlined spans open notes: apparatus for the Greek, rationale for both.

The engine — this site's code, its data contract, and its validators — is
open source. Clone the tabyo repository, put your
own base texts and overrides in `data/`, and build a static edition of your
own. See the repository README for the data contract in full, and
[sources](/sources/) for what the demo text is built on.
